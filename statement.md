# RECIPEbank

## Problem Statement

Recipes scattered across notebooks, messages, and random places stay lost. This project solves that with a simple digital recipe book built in Python.

## Scope

Users can add recipes to the system, entering cooking time, ingredients, steps, and care notes. They're able to search for recipes, view them, and delete ones they no longer need.

And because recipe data is saved to a text file, everything persists when the program closes and reopens.

## Target Users

- Students
- Home cooks
- Anyone who wants to keep recipes organized

## Objectives

- To provide a simple way to store recipes.
- To make recipes easier to search and view.
- To store recipe information using file handling.
- To practice Python programming concepts.

## High-Level Features

- Add a new recipe
- Store cooking time
- Store ingredients
- Store cooking steps
- Store important cooking tips
- Search for a recipe
- View all recipes
- Delete a recipe
- Save recipes in a text file
